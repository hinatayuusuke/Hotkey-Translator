

### 3. どうすれば「揺れ」を止められるか？（解決策）

Fit-Only のロジック自体を変えずに、揺れを抑えるには**「入力」か「出力」にフィルタをかける**のが定石です。

#### A. 入力の安定化（枠の量子化）

OCRから渡された `baseRect` をそのまま使わず、**数ピクセル単位で丸める**ことで、微細なノイズを無視します。

* **実装例:** 幅と高さを `5px` 刻み（または `10px` 刻み）にする。
* 99px も 101px も → **100px** として扱う。
* これにより、1px のブレで計算結果が変わることを防げます。



#### B. 出力の安定化（ヒステリシス / 慣性）

計算された `newFontSize` を即座に適用せず、**「前回とほとんど変わらないなら更新しない」**というルールを追加します。

* **実装例:**
```csharp
// 前回のフォントサイズと比較
if (Math.Abs(currentFontSize - newFontSize) < 0.5) {
    // 変化が 0.5pt 未満なら、チラつき防止のため更新しない
    return currentFontSize; 
}
// 大きく変わった場合のみ更新
return newFontSize;

```


* さらに、縮小方向への変更には敏感に反応し（見切れ防止）、拡大方向への変更は少し遅延させる（安定化）といった非対称な制御を入れると、より自然になります.
