# Hotkey Translator ユーザー操作ガイド

## 1. このアプリでできること

Hotkey Translator は、画面またはアクティブウィンドウの指定範囲をキャプチャし、OCR で文字を読み取り、翻訳結果をオーバーレイ表示する Windows アプリです。

設定内容は基本的に変更後に自動保存されます。画面内に保存ボタンはありません。

## 2. まず使ってみる

### 2.1 基本設定

1. 左側の「概要」を開きます。
2. 「原文言語」で、画面に表示されている文字の言語を選びます。
3. 「翻訳先言語」で、翻訳後の言語を選びます。
4. 必要であれば、言語の間にある入替ボタンで原文言語と翻訳先言語を入れ替えます。
5. 「OCR エンジン」を選びます。
6. 「翻訳エンジン」で、使用する翻訳サービスを1つ以上有効にします。

「カスタム」を選んだ場合は、表示される入力欄へ言語名または言語指定を入力してください。

### 2.2 OCR 範囲を選ぶ

1. 「概要」の「ROI」で、使用するスロットを選びます。スロットは 1～10 です。
2. 「ROI を有効化」をオンにします。
3. 「ROI を選択」を押すか、既定の `F6` キーを押します。
4. 表示された範囲選択画面で、読み取りたい領域を指定します。

選択した範囲は現在の ROI スロットへ保存されます。複数の読み取り場所を使い分ける場合は、スロットを切り替えてそれぞれの範囲を登録してください。

### 2.3 OCR と翻訳を実行する

翻訳したい画面を表示して、既定の `F8` キーを押します。「概要」の「テスト実行」でも同じ操作ができます。

処理中は進行状況が表示されます。キャンセル可能な処理では「キャンセル」ボタンが表示されます。完了すると翻訳結果がオーバーレイへ表示されます。

### 2.4 オーバーレイを表示・非表示にする

既定の `F9` キーでオーバーレイ表示を切り替えます。

## 3. 既定のホットキー

| 操作 | 既定キー |
| --- | --- |
| OCR／翻訳を1回実行 | `F8` |
| オーバーレイ表示切替 | `F9` |
| 強制実行 | `F10` |
| ROI を選択 | `F6` |
| OCR 対象ウィンドウを固定 | `F7` |
| OCR 対象ウィンドウの固定を解除 | `Shift` + `F7` |
| ミラーフルスクリーン切替 | `Ctrl` + `Shift` + `F7` |

その他のホットキーは初期状態では無効です。「ホットキー」画面でキーと `Ctrl`、`Alt`、`Shift` の組み合わせを設定できます。キー欄で「Disable」を選ぶと、その操作のホットキーは無効になります。Win キーには対応していません。

## 4. メイン画面の見方

画面左側のメニューから次の項目を選びます。

- 概要
- キャプチャ
- OCR 設定
- OCR エンジン
- VisionLLM
- オーバーレイ
- 自動翻訳
- Hook
- 翻訳
- ホットキー
- システム

画面下部の「プレビュー」を押すと、OCR 入力画像と固定ターゲットの確認領域を開閉できます。「ログ」を押すと実行ログを開閉できます。

プレビュー内の「OCR」タブには、直近の OCR 前処理画像が表示されます。「固定」タブには固定中のキャプチャ対象が表示されます。各プレビューをクリックすると拡大表示できます。

## 5. 「概要」画面

### 5.1 クイック操作ホットキー

現在設定されている次のホットキーを確認できます。

- OCR／翻訳を実行
- オーバーレイ切替
- ROI を選択
- OCR 対象ウィンドウを固定

### 5.2 現在の構成

現在のキャプチャ方式、プロバイダー、OCR エンジン、翻訳エンジン、Hook／Fullscreen、ROI の状態をまとめて確認できます。

### 5.3 言語と操作

- 原文言語と翻訳先言語を選択します。
- OCR エンジンを選択します。
- WinRT で必要な言語パックが不足している場合は「インストール」を使用します。
- DeepL、GoogleWeb、Gemini、LlamaCpp から使用する翻訳エンジンを有効にします。
- ROI スロットを選び、ROI の有効／無効を切り替えます。
- 「テスト実行」で現在の設定を使った OCR／翻訳を実行します。

複数の翻訳エンジンを有効にした場合、実際に試す順番は「翻訳」画面の「翻訳優先順位」に従います。

### 5.4 表示のクイック設定

- オーバーレイ文字サイズを調整します。
- オーバーレイ不透明度を調整します。
- 「固定 ROI オーバーレイモード」を有効にすると、翻訳表示位置を固定できます。
- 固定先は「ROI」または「ユーザーフレーム」から選べます。
- 「ユーザーフレーム」を選んだ場合は「ユーザーフレームを選択」で表示範囲を指定します。

固定オーバーレイの設定は翻訳の表示位置だけを変更し、OCR の読み取り範囲は変更しません。

### 5.5 Hook／Fullscreen

Graphics Hook パイプライン、Hook 内オーバーレイ描画、ミラーフルスクリーンをすばやく有効／無効にできます。Hook API は DX11、DX9、Vulkan から選択します。詳細は「Hook」画面で設定します。

## 6. 「キャプチャ」画面

### 6.1 モード

- 画面: 画面全体を基準にキャプチャします。
- アクティブウィンドウ: 現在アクティブなウィンドウを基準にキャプチャします。

### 6.2 プロバイダー

- WGC
- DXGI
- GDI

通常は動作するプロバイダーを1つ選びます。対象アプリを固定して使う場合は「固定のみ」を有効にし、`F7` で対象ウィンドウを固定してください。固定を解除するには `Shift` + `F7` を押します。

## 7. 「OCR 設定」画面

通常は既定値のまま使用し、文字の結合や認識結果に問題がある場合に調整します。

### 7.1 OCR チューニング

- pHash しきい値: 前回画像との差を判定する感度を調整します。
- IoU しきい値: OCR 領域同士の重なり判定を調整します。
- 書字方向: 自動、縦書き強制、横書き強制から選びます。
- 簡易マージ調整: 横書き／縦書きの文字領域をまとめる強さを調整します。

### 7.2 OCR 前処理（二値化）

二値化、自動しきい値、ガンマ補正、グレースケール変換、コントラスト調整を組み合わせて、OCR に渡す画像を調整できます。

「2段階 OCR」を有効にすると low／high の2種類のしきい値で認識します。「有効時は自動しきい値を優先」をオンにすると、自動しきい値が優先されます。

### 7.3 OCR 入力

「OCR 入力をダウンサンプル」を有効にすると、OCR に渡す画像を縮小できます。倍率を調整し、下部の「プレビュー」で入力画像を確認してください。縮小しすぎると小さい文字を認識しにくくなります。

## 8. 「OCR エンジン」画面

### 8.1 PaddleOCR Core

検出モデル、認識モデル、検出しきい値、認識スコアしきい値を設定します。認識モデルの「自動」は「概要」の原文言語に従います。

「低信頼度の行を除外」を有効にすると、指定した信頼度未満の行を結果から除外します。この設定は PaddleOCR にだけ適用されます。

### 8.2 PaddleOCR-VL

パイプライン版、最大ピクセル数、レイアウトしきい値、最大新規トークン数、レイアウト検出、精度を設定します。空欄は自動設定として扱われる項目があります。

設定を実行中のホストへ反映するには「適用して再起動」を押します。「停止」で PaddleOCR-VL ホストを停止できます。

## 9. 「VisionLLM」画面

OCR エンジンに VisionLLM を選ぶ場合のローカル VLM を設定します。

1. 「モデル」と「MMProj」を選びます。
2. 必要に応じてホスト、ポート、コンテキストサイズ、GPU layers、スレッド数、並列数、バッチサイズ、最大トークン数、最大画像辺長を設定します。
3. 「適用して再起動」で設定を反映します。

「再読込」はモデル一覧を更新し、「停止」は VisionLLM ホストを停止します。モデルファイルは `TranslationServiceLlama\LlamaCpp\Models` から読み込まれます。

「翻訳にも VisionLLM を使う」をオンにすると、OCR とローカル翻訳で同じ VisionLLM モデルを共有します。

「geometry assist hybrid OCR」を有効にすると、VisionLLM の認識文字を主結果として使い、選択した WinRT、NDL、PaddleOCR、OneOCR のいずれかをオーバーレイ配置用の位置情報として使います。

MTP は対応 GGUF モデルを使用する場合だけ有効にしてください。非対応モデルで有効にすると起動に失敗します。

## 10. 「オーバーレイ」画面

- オーバーレイ文字サイズを安定化: 認識結果が変化しても文字サイズが大きく変わりにくくなります。
- 小さい OCR ボックスの可読性を強化: 小さい領域の文字を読みやすくします。
- 小さい文字の感度: 可読性強化を適用する範囲を調整します。

## 11. 「自動翻訳」画面

画面の変化を監視して、自動的にオーバーレイを消したり OCR／翻訳を実行したりできます。

- シーン変化時の自動非表示
- シーン変化時の自動翻訳
- 自動翻訳バッジアイコン
- quiet window と待機時間
- テキスト重み付きスコアリング
- 監視間隔
- 監視 pHash しきい値

監視間隔を短くすると反応は速くなりますが、処理負荷が増える場合があります。誤検知が多い場合は監視 pHash しきい値や quiet window を調整してください。

## 12. 「Hook」画面

通常の画面キャプチャで取得できないゲームや全画面アプリを対象にする場合に使用します。

### 12.1 Graphics Hook

1. 「Graphics Hook パイプラインを有効化」をオンにします。
2. 対象に合わせて Hook API を DX11、DX9、Vulkan から選びます。
3. 必要に応じて Hook 内オーバーレイ描画を有効にします。
4. キャプチャ FPS 上限を設定します。

DX9 は画面上で「capture-only planned」と表示される開発中の選択肢です。

「hook エラー時に legacy capture へフォールバック」を有効にすると、Hook 失敗時に従来のキャプチャ方式を試します。診断が必要な場合だけ、診断欄の性能ログや診断ファイル出力を有効にしてください。

### 12.2 Launcher

1. 「Graphics Hook launcher を有効化」をオンにします。
2. 「参照...」で対象 EXE を選びます。
3. 必要であれば Launcher 引数を入力します。
4. 「Hook 起動」を押します。

Steam タイトルでは「コピー」で起動オプションをクリップボードへコピーし、Steam 側の対象タイトルの起動オプションへ貼り付けます。

### 12.3 ミラーフルスクリーン

「ミラーフルスクリーンモードを有効化」をオンにし、必要に応じて Magpie プロファイル index を指定します。既定の `Ctrl` + `Shift` + `F7` でも切り替えられます。

## 13. 「翻訳」画面

### 13.1 翻訳優先順位

一覧で翻訳エンジンを選択し、「上へ」「下へ」で使用順を変更します。有効なエンジンが失敗した場合は、一覧の次のエンジンが試されます。

### 13.2 ローカル Llama.cpp

1. 使用する GGUF モデルを選びます。
2. 「再読込」でモデル一覧を更新します。
3. 必要に応じてホスト、ポート、コンテキストサイズ、GPU layers、スレッド数、並列数、バッチサイズ、最大トークン数、temperature、Top P、Top K、repeat penalty を設定します。
4. 「Llama.cpp を再起動」で設定を反映します。

「llama-server を停止」でサーバーを停止できます。メモリを完全に解放するには、対象機能をオフにしてアプリを再起動してください。モデルファイルは `TranslationServiceLlama\LlamaCpp\Models` から読み込まれます。

MTP は対応 GGUF モデルを使用する場合だけ有効にしてください。

### 13.3 DeepL

DeepL API キーと endpoint を入力します。API キーは画面上で伏せ字表示されます。

### 13.4 Gemini

Gemini API キーを入力し、モデルを選びます。「再読込」で利用可能なモデル一覧を更新します。API キーは画面上で伏せ字表示されます。

## 14. 「ホットキー」画面

各操作について、キーと `Ctrl`、`Alt`、`Shift` の組み合わせを設定します。設定できるキーは `F1`～`F12` と `A`～`Z` です。

設定対象には次の操作があります。

- 1回実行
- 次／次の次の ROI スロットを実行
- オーバーレイ切替
- 強制実行
- 次／次の次の ROI スロットを強制実行
- Gemini 画像翻訳
- オーバーレイテキスト
- シーン自動翻訳
- ROI を選択
- ROI を選択して翻訳
- ユーザーフレームを選択
- ウィンドウ固定／固定解除
- ミラーフルスクリーン切替

同じキーの組み合わせを複数の操作へ割り当てると競合表示が出ます。競合がなくなるように変更してください。

一部のアプリで通常のホットキーが反応しない場合は、「RawInput ホットキーバックエンド」を試せます。この機能は experimental です。

## 15. 「システム」画面

### 15.1 外観

- テーマ: ダークまたはライトを選びます。
- UI 言語: システム、English、日本語から選びます。

### 15.2 クリップボード

「オーバーレイ更新後にOCR原文と翻訳文をクリップボードへコピー」をオンにすると、オーバーレイ更新時に認識した原文と翻訳文がクリップボードへコピーされます。既存のクリップボード内容は置き換えられます。

### 15.3 性能

VRAM 予算プロファイルを低 VRAM、標準、高 VRAM、超高 VRAMから選びます。この設定は同時に常駐させる OCR／翻訳ホスト数を制御します。使用可能な VRAM に合わせて選んでください。

ログ、OCR 性能ログ、ログ閾値も設定できます。通常は問題の調査が必要な場合だけ性能ログを有効にします。

### 15.4 設定管理

「全設定をリセット」を押し、確認すると、保存済み設定が初回起動時の既定値へ戻ります。この操作は現在のカスタム設定を失うため、必要な値を控えてから実行してください。

## 16. 困ったとき

### ホットキーが反応しない

- 「ホットキー」画面でキーが「Disable」になっていないか確認します。
- 競合表示が出ていないか確認します。
- 対象アプリを管理者権限で動かしている場合は、権限差の影響がないか確認します。
- 通常方式で反応しない場合は RawInput ホットキーバックエンドを試します。

### OCR できない、または文字が崩れる

- 原文言語と OCR エンジンが対象文字に合っているか確認します。
- ROI が文字を含む範囲になっているか確認します。
- 下部の「プレビュー」で OCR 入力画像を確認します。
- 二値化、ガンマ、コントラスト、ダウンサンプルを1項目ずつ調整します。
- PaddleOCR を使う場合は認識モデルと信頼度しきい値を確認します。

### 翻訳されない

- 「概要」で翻訳エンジンが1つ以上有効か確認します。
- DeepL または Gemini を使う場合は API キーを確認します。
- ローカルモデルを使う場合はモデル選択後にランタイムを再起動します。
- 下部の「ログ」を開き、エラー内容を確認します。

### オーバーレイの位置が合わない

- ROI の選択範囲を確認します。
- 固定 ROI オーバーレイモードの対象が「ROI」か「ユーザーフレーム」か確認します。
- ユーザーフレームを使用する場合は、もう一度表示範囲を選択します。
- VisionLLM を使う場合は geometry assist hybrid OCR を試します。

### 全画面アプリをキャプチャできない

- 「Hook」で Graphics Hook を有効にし、対象アプリに合う API を選びます。
- Launcher から対象アプリを起動するか、Steam 起動オプションを設定します。
- Hook に対応しない場合は legacy capture へのフォールバックを試します。
